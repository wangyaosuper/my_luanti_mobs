16px Texture Mod for Minetest - Ephesus Blocks (Project)

This 16px texture mod for Minetest has been specially created for an exciting project.


Installation Instructions:
1. Download the .zip file of the 16px texture mod.
2. Copy the .zip file into the "mods" folder of your Minetest installation.
3. Activate the mod in the "Settings" menu of Minetest.
4. For more experience:


Compatibility
- use i3 mod: 
"https://content.minetest.net/packages/jp/i3/" 

- and stairplus mod (Highly recommended) 
"https://content.minetest.net/packages/Calinou/moreblocks/ " 

This texture mod is designed for our ongoing project and may be expanded upon in the future. We appreciate your feedback, suggestions, and contributions to enhance this unique visual experience.
